## Reporting a Vulnerability

If you have a security vulnerability in Lustre code you wish to report, please
email security@whamcloud.com and security@thelustrecollective.com with details.

Please do not file a public JIRA issue for a security vulnerability -
we do not want to draw attention to the vulnerability until a fix has been
developed and administrators have been alerted and have had some time to put
a mitigation in place.

Ideally the reporting email should have as much detail as possible:

- reproducer, versions affected, fix if available, etc.
- indicate to whom (individual and/or affiliation) credit for finding the
  issue should be reported (if any)
- details of any CVE already reserved
- your intentions around disclosing the details of the vulnerability

We aim to respond to any such reports within three business days of receipt.
